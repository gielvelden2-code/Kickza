# Kickza

Kickza is een installeerbare voetbal-PWA. Deze eerste versie is een **interactieve demo met fictieve gegevens**, geen echte livescore-feed.

## Functies
- Wedstrijden, filters en favorieten (lokaal opgeslagen)
- Wedstrijdverslag en demonstratie van Match Pulse
- Competitiestanden en Player Battle (testdata)
- Voorspellingen voor uitslagen, topscorer en assists (lokaal opgeslagen)
- Installatie als PWA, offline caching en automatische GitHub Pages workflow

## Publiceren
In de repository: Settings > Pages > Build and deployment > GitHub Actions. De workflow publiceert na een push naar main. Open daarna https://gielvelden2-code.github.io/Kickza/ .

## Belangrijk
Er is **geen** voetbal-API, realtime doelpuntinformatie, automatische puntentelling, gebruikerslogin of live videostream geïntegreerd. Voor een productie-app zijn een gelicentieerde databron, beveiligde backend en autorisatie nodig. Het pictogram is een tijdelijke vectorbenadering van het aangeleverde logo.
